# Windows Event Monitor

A Python-based security monitoring tool that analyzes Windows Security Event Logs and identifies authentication-related security events.

## Features

* Reads Windows Security Event Logs
* Identifies Security Event IDs
* Maps Event IDs to human-readable descriptions
* Summarizes security activity
* Supports authentication monitoring
* Provides security event analysis

## Technologies Used

* Python
* pywin32
* Windows Event Logs

## Current Capabilities

* Detects successful logon events (4624)
* Detects privileged logon events (4672)
* Analyzes Windows Security Log activity
* Summarizes event occurrences

## Future Improvements

* Failed login detection (4625)
* Brute force detection
* Report generation
* CSV export functionality
* Alerting capabilities
