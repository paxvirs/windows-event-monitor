# Windows Event Monitor

A Python based security monitoring tool that analyzes Windows Security Event Logs and provides insight into authentication and credential-related activities.

## Project Overview

This project was developed to improve Windows log analysis skills and demonstrate the ability to work with real security telemetry using Python.

The tool reads Windows Security Event Logs, identifies key security events, and provides a summary of observed activity.

## Features

* Reads Windows Security Event Logs
* Identifies important Event IDs
* Maps Event IDs to human-readable descriptions
* Summarizes security-related activity
* Supports authentication monitoring
* Provides event occurrence statistics

## Technologies Used

* Python
* pywin32
* Windows Event Viewer
* Git
* GitHub
